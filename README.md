# NorthPeak Digital — Web Development Qualification Task

Built for the **Digital Heroes Qualification Task** (Role 05 — Web Development).

## 🚀 Overview
NorthPeak Digital is a responsive agency website engineered with React, Tailwind CSS, and TypeScript.

### Required Features Built:
- **Hero Section**: Headline, subheadline, dual CTAs, and live metric stats.
- **6 Core Services**: Bespoke Web Dev, Shopify Architecture, Speed Optimization, CRO, Custom APIs, Technical SEO.
- **Results & Testimonials**: Client metrics and case studies.
- **3 Pricing Tiers**: Clear pricing cards with feature checklists.
- **Contact Form**: Form with client-side validation.
- **Mandatory Footer Credit**: `"Built for Digital Heroes Training Task"` linked to `https://digitalheroesco.com`.

---

## 🛠️ Tech Stack
- React + Vite + TypeScript
- Tailwind CSS + Lucide Icons
- TanStack Router

---

## ⚡ Local Setup
```bash
bun install  # or npm install
bun run dev  # or npm run dev
```

To build for production:
```bash
bun run build # or npm run build
```
